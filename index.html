UX Design

📱 StudyMate Design Thinking

This section documents the end-to-end UX wireframing methodology for the StudyMate college management app.

1. Empathize

Student Need Finding

College students frequently struggle with managing notes, tracking upcoming assignment due dates, reviewing course syllabi, and checking class timetables across multiple disconnected platforms (emails, messaging groups, physical notebooks, college portals).

2. Define

Problem Statement

Students need a simple, centralized mobile application to organize all core academic activities in one low-friction hub to prevent missed deadlines and improve study focus.

3. Ideate

Key Solutions

  • Single-Page Mobile App layout with quick-access cards for Courses, Notes, Tasks, and Timetable.
  • Unified search bar for instant lookup across subjects & notes.
  • Low-cognitive-load wireframe aesthetic for distraction-free navigation.
4. Prototype

Low-Fidelity Mobile Wireframes

Created interactive monochrome wireframe screens with placeholder icons, crisp structural borders, quick action buttons, and clear typography hierarchy.

5. Test

Usability & Navigation Check

Evaluated whether students can smoothly execute core tasks: navigating between screens, filtering notes by subject, adding assignments, and checking weekly timetables without broken flows.
